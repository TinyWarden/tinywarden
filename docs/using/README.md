# Use TinyWarden

Use Dashboard for current attention, a server page for its evidence, and History for
sampled state changes. Administrators manage skills and settings; ordinary users
see only servers granted to them. [Page access and URLs](../reference/navigation.md)
list the available screens.

- [Dashboard and customization](dashboard.md)
- [Fleet management](fleet.md)
- [Maintain Debian packages](package-maintenance.md): refresh indexes, review exact
  conservative upgrades and follow verification or recovery.
- [Server details and reading history](servers.md)
- [Skills, settings and monitored services](skills.md)
- [History and notifications](history.md)
- [System settings and permissions](settings.md)
- [Accounts, passwords and email verification](accounts.md)

A green result applies to a configured check's scope. It does not establish that
every service, filesystem, package or application on the host is healthy. A page
refresh reads existing evidence; **Run now** requests a new collection.
